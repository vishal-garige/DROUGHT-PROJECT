# Drought Severity Assessment using NDVI and GIS

This project focuses on drought severity assessment in the Hyderabad region using Remote Sensing and GIS techniques.

## Tools Used
- QGIS
- Python
- Landsat 9 Imagery
- USGS EarthExplorer

## Methodology
- Downloaded Landsat 9 imagery
- Calculated NDVI
- Classified vegetation health
- Generated drought severity maps

## Outputs
- NDVI Raster
- Drought Severity Map
- GIS Layout Map
